# Investing

個人の投資関連情報の入口です。

## このVaultに置くもの

- 個人の投資方針
- 個人portfolio
- 個人watchlist
- 銘柄ごとのinvestment thesis
- 売買・見送り等の判断理由
- 個人向け調査メモ

## 共同Vaultへ置くもの

二人で共有すると明示した次のような情報は `hiroyuki9614/hr-vault` を共同正本とします。

- 共同portfolio
- 共同watchlist
- 共同の資産配分方針
- 二人で決めた投資判断
- 共同通知条件

個人メモを共有しただけで、個人側の非公開な理由・感情・補足まで共有対象にしません。

## 通知・株価収集

株価取得、暴落判定、ntfy / Telegram等の通知コードはデータ正本ではありません。ここへ複製せず、共通toolkitまたは外部adapterから利用する方針です。

## 推奨ファイル

実データを入れる前にrepositoryがprivateであることを確認してください。

- `investment-policy.md`
- `portfolio.md`
- `watchlist.md`
- `theses/<symbol>.md`
- `decisions/`
